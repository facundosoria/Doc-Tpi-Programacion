# Vocabulario del castellano rioplatense y tecnico que el diccionario es-es no trae.
#
# Este archivo NO es vocabulario del proyecto: es un hueco del diccionario, y
# cualquier equipo argentino escribiendo documentacion tecnica lo necesita igual.
# Por eso vive en config/ (generico) y no en config/proyecto/.
#
# Tres familias, sembradas del corpus real (423 KB), no adivinadas:
#
#   1. VOSEO           el diccionario es-es no conjuga vos: "pusheas", "mira",
#                      "corregila", "tenes". Es la familia mas grande.
#   2. TECNICISMOS     "deterministico", "asincronico", "anonimizacion",
#                      "idempotencia": castellano tecnico correcto pero ausente.
#   3. ANGLICISMOS     verbos del oficio ya castellanizados: "mergear", "parsear",
#                      "mockear", "loguear", "pushear".
#
# Antes de sembrarlo se revisaron las 355 palabras una por una buscando faltas
# reales. No habia ninguna: los seis casos sospechosos resultaron ser nombres de
# archivo e identificadores dentro de diagramas Mermaid.
#
# Se sumo despues una cuarta familia, chica:
#
#   4. MALAS PALABRAS  rioplatenses ("boludo", "pelotudo", "chabon", "sorete").
#                      NO son vocabulario del proyecto: aparecen citadas como
#                      ejemplos en la documentacion del moderador de chat, que
#                      justamente explica por que una lista peninsular no sirve
#                      aca. Ver ADR-012 y docs/04 §2.3.3. Que esten en el
#                      diccionario del corrector ortografico no dice nada sobre
#                      si el moderador las bloquea: eso lo decide el nivel por
#                      termino de su propia lista, que es otro archivo.
