GUÍA RÁPIDA

Cómo usar TUP-Golde-Set

Configurá una evaluación pedagógica trazable en cuatro pasos. La plataforma analiza el uso del tutor de IA; no reemplaza la calificación académica ni las pruebas determinísticas del curso.

↗

ORDEN RECOMENDADO

Primero definí qué es una buena respuesta; después validá al evaluador.

El flujo se guarda por versiones: publicar una nueva rúbrica o un Golden Set no modifica una calibración activa.

  1. 01

    DEFINIR EL CRITERIO

    Creá y publicá una rúbrica

    En cada dimensión indicá el criterio, el ancla JSON, el prompt y el peso. El ancla es el ejemplo estructurado que le muestra al modelo cómo se expresa cada nivel de desempeño.

    Ir a Rúbricas
  2. 02

    APORTAR REFERENCIAS

    Armá y publicá el Golden Set

    Cargá casos representativos con la conversación, la autoría y los puntajes de referencia definidos por una persona docente. Podés usar casos sintéticos o interacciones anonimizadas elegibles.

    Ir a Golden Set
  3. 03

    VALIDAR EL MODELO

    Ejecutá una calibración

    Elegí la rúbrica publicada, el Golden Set publicado y el modelo desplegado. La corrida compara sus resultados con tus referencias y muestra métricas, errores y trazabilidad.

    Ir a Calibraciones
  4. 04

    HABILITAR EL USO

    Activá la calibración aprobada

    Al activarla, las nuevas evaluaciones quedan asociadas a esa versión. Revisá en Asignaciones los desafíos vinculados y cualquier evaluación que haya quedado en cola mientras el servicio estaba suspendido.

    Ver Asignaciones y cola

PUNTOS IMPORTANTES

Preguntas frecuentes

¿Por qué veo “Sin calibración activa”?

Es el estado esperado hasta que una corrida aprueba y se activa. Mientras tanto, las evaluaciones de IA se encolan de forma segura; no se pierde información.

¿Una rúbrica o Golden Set publicado se usa automáticamente?

No. Primero tenés que ejecutar una calibración con esas versiones y activar la corrida aprobada. Así cada evaluación conserva su contexto reproducible.

¿Qué se evalúa?

La interacción pedagógica con el tutor de IA, según la rúbrica de la cátedra. La nota académica se conserva fuera de este módulo.
