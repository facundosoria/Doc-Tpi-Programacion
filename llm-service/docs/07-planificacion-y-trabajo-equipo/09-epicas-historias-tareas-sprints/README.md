# Planificación detallada: épicas, historias, tareas y sprints

Esta carpeta es el punto de entrada único para el trabajo del equipo. El contenido completo está
separado por tipo de artefacto para que una historia y su desglose de tareas nunca ocupen el mismo
camino ni puedan sobrescribirse:

1. [Épicas](epicas/README.md): propósito y fronteras de cada épica.
2. [Historias de usuario](historias/README.md): criterios de aceptación y escenarios BDD.
3. [Tareas SMART](tareas/README.md): desglose técnico de cada historia. La guía completa de
   tareas que antes ocupaba este índice se conserva allí, sin pérdida de contenido.
4. [Sprints](sprints/README.md): capacidad, compromiso, demo y cierre por iteración.

Las preguntas de la auditoría se mantienen una sola vez en
[`PREGUNTAS-ABIERTAS.md`](PREGUNTAS-ABIERTAS.md). Los índices de cada subcarpeta enlazan a ese
contenido; no se crean copias por tipo de artefacto.

## Orden recomendado

Leé primero la [guía general de planificación](../README.md), después este índice y luego las
cuatro carpetas anteriores en el orden 1→4. Para construir una historia, consultá su épica,
la ficha de HU, sus tareas y el sprint donde se compromete. Las plantillas están centralizadas en
[`../10-plantillas/`](../10-plantillas/README.md) y los contratos de integración en
[`../../contracts/`](../../contracts/README.md).

## Reglas de conservación

- Los archivos de épicas, historias, tareas y sprints conservan el texto completo de sus fuentes.
- Un índice solo orienta: no reemplaza ni resume las fichas.
- Las correcciones se aplican en el documento canónico y se registran en
  [`registro/`](../../registro/).
