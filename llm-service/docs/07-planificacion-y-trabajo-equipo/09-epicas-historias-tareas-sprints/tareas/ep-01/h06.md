# Tareas SMART — LLM-EP01-H06 (ex-H09) · Suite de pruebas y guía de demo de S1

> [template de Tarea de Taiga](../../../10-plantillas/tarea-taiga.md); método **SMART**

### T1 — Unitarias de reglas de dominio

- **Específica:** escribir las unitarias de reglas de dominio (cálculo de rúbrica,
  invariantes, validaciones) sin Spring ni red.
- **Medible:** las unitarias pasan y cubren las reglas de dominio de H04.
- **Alcanzable:** 4 h, una persona.
- **Relevante:** base de la cobertura exigida por [24](../../../../06-operacion-calidad-y-pruebas/02-convenciones-de-cobertura.md).
- **Acotada:** 4 h · paso *unidad*. **Depende de:** H04 · **Traza:** CA1, CA2 de H09.

### T2 — Integración de persistencia y migración

- **Específica:** pruebas de integración de persistencia y migración con Testcontainers /
  Flyway desde base vacía.
- **Medible:** la migración corre reproducible y las lecturas/escrituras persisten en la prueba.
- **Alcanzable:** 3 h, una persona.
- **Relevante:** verifica el esquema de H04 de punta a punta.
- **Acotada:** 3 h · paso *integración*. **Depende de:** H04 · **Traza:** CA1 de H09.

### T3 — Pruebas de contrato del Gateway con WireMock

- **Específica:** pruebas de contrato del Gateway con WireMock que ejercitan headers,
  `401`/`403` e idempotencia.
- **Medible:** las pruebas de contrato pasan para los casos de autorización e idempotencia.
- **Alcanzable:** 3 h, una persona.
- **Relevante:** cubre los casos de seguridad de H03 y H05.
- **Acotada:** 3 h · paso *contrato / seguridad*. **Depende de:** H03, H05 · **Traza:** CA1 de H09.

### T4 — Prueba automatizada de reinicio de Compose

- **Específica:** prueba automatizada que reinicia Compose y verifica que el golden set persiste.
- **Medible:** tras el reinicio la prueba encuentra el golden set cargado antes; si no, falla.
- **Alcanzable:** 3 h, una persona.
- **Relevante:** es la garantía de la demo de S1.
- **Acotada:** 3 h · paso *resiliencia*. **Depende de:** H02·T1, H06 · **Traza:** CA3, CA6 de H09.

### T5 — Ejecutar los escenarios BDD de aceptación de H05–H07

- **Específica:** ejecutar los escenarios BDD (camino feliz + negativos) de H05, H06 y H07 y
  dejar la evidencia enlazada.
- **Medible:** cada escenario BDD de H05–H07 tiene evidencia de ejecución enlazada.
- **Alcanzable:** 3 h, una persona por pareja.
- **Relevante:** cierra la validación de las HU de valor de S1.
- **Acotada:** 3 h · paso *E2E*. **Depende de:** H05, H06, H07 · **Traza:** CA1 de H09.

### T6 — Guía de demo paso a paso + gate de cobertura

- **Específica:** escribir la guía de demo (acceso autorizado → alta → carga → consulta tras
  reinicio), ejecutable en ambiente integrado, y activar el gate de cobertura de
  [24](../../../../06-operacion-calidad-y-pruebas/02-convenciones-de-cobertura.md) en CI.
- **Medible:** la guía se sigue paso a paso y termina en la consulta tras reinicio; CI falla si la cobertura baja del umbral.
- **Alcanzable:** 2 h, una persona.
- **Relevante:** evidencia reproducible para la Review.
- **Acotada:** 2 h · paso *E2E / demo*. **Depende de:** T1–T5 · **Traza:** CA4, CA5 de H09.

> **Total H09:** 18 h.
