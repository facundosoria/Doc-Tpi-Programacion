# Plantillas de trabajo

Esta carpeta contiene las plantillas reutilizables para cargar el trabajo en Taiga y registrar
cada iteración. No son historias, tareas ni sprints concretos: sirven como formato común para
crear esos documentos sin copiar contenido entre fichas.

## Orden de uso

1. [Épica](epica-taiga.md): objetivo, restricciones, criterios de aceptación e impactos.
2. [Historia de Usuario](historia-de-usuario-taiga.md): Como/Quiero/Para, criterios, BDD,
   prototipo, estimación y dependencias.
3. [Tarea SMART](tarea-taiga.md): paso técnico medible trazado a una historia.
4. [Sprint](sprint-llm.md): identificación, capacidad, compromiso, revisión y retrospectiva.
5. [Página Wiki de grupo](pagina-wiki-grupo.md): estructura para publicar el material del equipo.

Las fichas completas viven en [`../09-epicas-historias-tareas-sprints/`](../09-epicas-historias-tareas-sprints/);
las plantillas no duplican ninguna de ellas.
