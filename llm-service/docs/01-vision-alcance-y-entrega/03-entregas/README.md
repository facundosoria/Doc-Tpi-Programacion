# 03 — Entregas y evidencias

Esta carpeta reúne los documentos que se prepararon para una entrega, una sesión de integración o
una verificación concreta. Son evidencia y material operativo: para conocer una regla vigente,
volvé primero a `00 — Gobierno`, al alcance o al contrato correspondiente.

## Orden de consulta

1. [entrega-1.md](entrega-1.md) — alcance y evidencia de la primera entrega.
2. [checklist-cierre-s1.md](checklist-cierre-s1.md) y
   [backlog-priorizado-cierre-s1.md](backlog-priorizado-cierre-s1.md) — qué verificar al cerrar S1.
3. [resumen-planning-cierre-s1.md](resumen-planning-cierre-s1.md) — contexto de planificación y
   decisiones de cierre.
4. [ep-03-s1-verificacion.md](ep-03-s1-verificacion.md),
   [ep-08-verificacion.md](ep-08-verificacion.md) y
   [verificacion-v2-golden-set-calibracion.md](verificacion-v2-golden-set-calibracion.md) —
   evidencia específica de Golden Set, calibración y moderación (EP-08).
5. [sesion-integracion-agenda.md](sesion-integracion-agenda.md) — acuerdos pendientes con otros
   equipos; usar junto con [`contracts/`](../../contracts/README.md).
