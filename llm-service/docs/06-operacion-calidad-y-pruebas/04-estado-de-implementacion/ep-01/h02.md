## Hallazgos y correcciones (2026-09-21)

1. **Sin `.env`, `up` falla** (`required variable LLM_CREDENTIALS_MASTER_KEY is missing`) y **sin la red `tpi-platform`** también (`declared as external, but could not be found`). Ambos verificados. README corregido.
2. **`smoke-compose.sh` no corría** en una máquina con contenedores previos: `container_name: tpi-llm` fijo (`Conflict. The container name "/tpi-llm" is already in use`; el 2026-09-21 se renombró a `llm-service`, el nombre del servicio en Eureka) y la red `llm-default` de otro proyecto. El mismo choque afecta al `up` manual; se documentó. El script ahora usa un override con nombres propios y genera la clave si falta.
3. **`.dockerignore` excluía `docs`, no `docsV2`**: cualquier cambio de documentación invalidaba la capa `COPY . ./` y forzaba a Maven a bajar las dependencias de nuevo. Agregado `docsV2`.

## Pendiente (no es código)

- Referente de producto y Responsable/Suplente sin asignar (Planning).
