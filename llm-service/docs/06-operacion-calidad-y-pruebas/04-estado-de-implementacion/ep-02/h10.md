## Qué se agregó

Portado (adaptado, no copiado literal) de `codigo-ejemplo/ms-evaluacion-llm`
(`LlmGateway`/`LlmGatewayImpl`/`GroqAdapter`), luego eliminada esa carpeta — ver
[decisión de consolidación](../codigo-ejemplo/README.md).

- `domain/ai/`: `ModelFunction`, `ModelInvocationRequest`/`Result`, `ModelInvocationPort`,
  `ModelResponseSchema` (+ `InvalidModelResponseException`, `ModelTimeoutException`) — java puro,
  sin Spring (regla de doc 37 §1).
- `infrastructure/ai/FakeModelAdapter` — el adaptador fake de T3; nunca llama a un proveedor real
  (a diferencia de `GroqAdapter`, acá no hay rama "real" que activar con una API key).
- `infrastructure/persistence/FunctionModelConfigRepository` + migración `V23` (`V23__ai_gateway_and_tutor.sql`; tabla
  `function_model_config`, T5) — semilla `('tutor','fake','fake-socratic-v1')`.
- `application/ModelInvocationService` — resuelve la función, invoca el puerto con timeout
  (`java.util.concurrent.CompletableFuture` + `Executors.newVirtualThreadPerTaskExecutor()`),
  valida el schema.
- `api/ModelAssignmentController` — `GET`/`PUT /api/llm/model-assignments/{function}`, tal cual
  `docs/contracts/llm-service-v1.openapi.yaml`.

| Tarea | Pide | Estado |
