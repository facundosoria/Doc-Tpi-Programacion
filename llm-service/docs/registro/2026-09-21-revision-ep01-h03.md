# Revisión de EP-01 · H03 tras la integración `main` → `dev` — 2026-09-21

## Decisión anterior

H03 figuraba 🟡 (evidencia del 2026-09-16) y la tarea T9 (`404` real para «no existe») estaba
pendiente desde la auditoría del 2026-09-12.

## Motivo

Al revisar H03 contra el código integrado: los endpoints devolvían `409` para recursos inexistentes
aunque el OpenAPI declara `404`; y `mvn verify` fallaba en el gate de JaCoCo (`domain` en 89,6 %,
mínimo 90 %) desde la integración, sin que ninguna corrida lo mostrara.

## Regla vigente

- «No existe» responde `404` Problem Details (`ResourceNotFoundException`); `409` queda para
  conflictos de estado.
- La verificación de cierre de una historia es `mvn -o verify -Dintegration=true` (unitarios, ITs,
  tests de esquema y gate de JaCoCo), no solo `mvn test`.
- Resultado 2026-09-21: 685 unitarios + 99 de integración, 0 fallas, gate cumplido.
