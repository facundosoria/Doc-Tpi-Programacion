# Revisión de EP-01 · H04 tras la integración `main` → `dev` — 2026-09-21

## Decisión anterior

H04 figuraba 🟢 con `V1IsolatedSchemaTest` y `FlywaySchemaTest` como evidencia, y la nota decía que la
cadena completa eran 15 migraciones.

## Motivo

Ambos tests solo corren con `-Dintegration=true` y `mvn test` los muestra como *skipped*. Corridos, `FlywaySchemaTest`
fallaba desde la integración (`provider_key` obligatoria desde `V26`). Además CA2 («crear la base desde cero da
siempre lo mismo») no se probaba desde cero, y las 11 migraciones renumeradas +6 dejaron citas viejas.

## Regla vigente

- La cadena es `V1`–`V23`, `V26`–`V38`; el hueco `V24`/`V25` es intencional y un test lo protege.
- La reproducibilidad se prueba con dos bases nuevas y la cadena completa (versiones, checksums, columnas).
- Los tests de esquema se corren con `-Dintegration=true`; un *skipped* no es evidencia.
