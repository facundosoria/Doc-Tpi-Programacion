# Revisión de EP-01 · H06 (ex-H09) tras la integración `main` → `dev` — 2026-09-21

## Decisión anterior

La historia figuraba 🟢: 218 tests, gate de cobertura activo, script de reinicio y guía de demo «cumplidos».

## Motivo

Al ejecutar todo: el gate de JaCoCo estaba en rojo desde la integración; el script de reinicio fallaba
(`503 "Courses no está disponible"`); el `gateway-mock` apuntaba al puerto viejo 8080 y no inyectaba
`X-Principal-Type`; y la guía de demo tenía comandos que no funcionan.

## Regla vigente

- Una demo o un script de aceptación solo se da por cumplido si se ejecutó contra el stack real.
- El stack de demo incluye `courses-mock` y `gateway-mock` (`compose.workbench.yaml`, sin frontend): el servicio ya no funciona sin courses-service.
- El puerto del servicio es `8086` (API) y `8087` (management); `8080` es el del `gateway-mock`.
