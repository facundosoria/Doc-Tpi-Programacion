## Resumen (no duplica la ficha, que ya trae el detalle)

- Borrador/copia desde base publicada/publicación/versión siguiente, anonimización real
  (`RealCaseAnonymizer`, aplicada siempre, no opcional), importación masiva con commit atómico
  fila por fila.
- **Hueco abierto — origen de la base de plataforma.** `copyFromPublishedBase` **lee** una
  versión `scope = 'PLATFORM'` ya publicada, pero **no existe ningún endpoint que la cree**. El
  contrato v2 promete `GET /api/llm/admin/base-golden-sets` (`listBaseGoldenSets`) para
  descubrirla, pero **no hay ningún controller que lo implemente** — sin él, "copiar desde la
  base publicada" no tiene forma de descubrir qué `baseVersionId` usar salvo conociéndolo de
  antemano.
- El endpoint real `POST .../golden-sets/{versionId}/next-version` existe en el código pero no
  está en el contrato v2 publicado (el contrato versiona esto solo para rúbricas).
