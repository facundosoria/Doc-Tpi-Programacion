## Rule

Generate the base `docs/` tree so vision, contracts, backlog, epics, stories and sprints have a home before anything is written into them. Everything a project's planning docs produce lives under `docs/`.

### What it creates

- `docs/00-fuentes-de-verdad-y-convenciones.md` — the precedence hierarchy and the service's canonical identity (repo, `spring.application.name`, `/api/<n>/**` prefix, `aud`).
- Folders: `docs/vision/`, `docs/plan/`, `docs/backlog/`, `docs/contracts/`, `docs/epicas/`, `docs/historias/`, `docs/sprints/`, `docs/prototipos/`, `docs/plantillas/`, `docs/metodo/`, `docs/dor-dod.md`, `docs/importado/`.
- `docs/README.md` — index + the datum → single-source table.
- Fixed material copied in: Taiga epic and user-story templates, method guides, sprint register, DoR/DoD starter. STUBs where a later skill fills content.

### Layers (precedence order, fixed in docs/00)

| Priority | Source | Decides |
|---|---|---|
| 1 | Product docs / client PRD | Functional scope, phases, business rules, release criteria |
| 2 | Platform / cross-cutting architecture docs | Network, gateway, discovery, identity, routes, observability, integration tests |
| 3 | `docs/00`, the v1 contracts, the ADRs | How 1 and 2 apply to this service |
| 4 | Rest of `docs/` | Explanation and detail — may not contradict 1–3 |

Imported material from other teams goes in `docs/importado/`: historical, outside the hierarchy, never modified (corrections in a separate `.md`).

### Four disciplines the tree exists to enforce

1. **Single source** — each datum in exactly one document; everything else references it. On disagreement the single source wins.
2. **Source vs derived view** — source docs declare they *are* the source; derived views (epic/story fiches, sprint proposals) are Taiga presentation format, never a planning source, and open with a "what it is / what it is NOT" block.
3. **Traceability** — every story `Sxx-Hyy` links to its epic and a requirement (`RF-*` / `PAR-*`); the sprint says when.
4. **Honest header** — a STUB says "STUB — generated by skill X"; a story without points says "assigned in Sprint 0".
